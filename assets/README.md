# Native arayüz kaynakları

`fonts/`, `icons/` ve `themes/` RadioS'un C arayüz kaynaklarına ayrılmıştır. Tasarımın HTML/CSS/JS kopyası burada çalıştırılmaz; görsel referans `design/reference/tasarrım/` altındadır.

`fonts/InterVariable.ttf` resmi Inter 4.1 sürümünün değişken TTF dosyasıdır (SIL Open Font License 1.1, `fonts/LICENSE.txt` ile birlikte korunur). Uygulama pencere oluşmadan önce bu dosyayı Pango'nun DirectWrite font haritasına yükler; font yüklenemezse pencere açılmaz ve uygulama "Tasarımın Inter fontu yüklenemedi" hatasıyla çıkar. DirectWrite bu fontu "Inter Variable Text" ailesi olarak tanır; bu yüzden tema CSS'lerinde ve C kaynaklarında Inter kullanan her `font-family` listesi "Inter Variable Text" ile başlar, eski "Inter Variable"/"Inter" adları yedek olarak kalır. Inter'de bulunmayan arayüz simgeleri (▾ ▸ ⏭ ⏮ ⚙ ✎ ✕ …) için liste "Segoe UI Symbol", "Segoe UI Emoji", "Segoe UI" ve "Nirmala UI" ile sürer. `fonts/InterVariable.woff2` tasarımın kaynak dosyası olarak saklanır; DirectWrite WOFF2 okumadığı için çalışma zamanında kullanılmaz. Eşaralıklı ekran yazıları (`themes/dj-pedals.css`) "Cascadia Mono", Consolas sırasını kullanır.

`themes/radios.css`, build sırasında kaynak tasarım CSS'lerinden üretilen kuralları GTK düğüm/yerleşim ayrıntıları için tamamlar. Analog saat, knob ve ölçerler C/Cairo ile çizilir. Uygulama simgesi için `icons/README.md` dosyasına bakın.
