# packaging fails: a new dependency needs its licence recorded here before it can ship.

# Format (one rule per line, fields separated by " | "):
#   <regex on the lower-case file name, or @always> | <component> | <SPDX expression> | <texts>
# <texts>: comma-separated, each one of
#   msys2:<path below RADIOS_MSYS2_PREFIX/share/licenses>   copied to share/licenses/<path>
#   ffmpeg:<path below RADIOS_FFMPEG_PREFIX>                 copied to share/licenses/ffmpeg/<file>
#   wheel:<path inside the pinned tzdata wheel>              copied to share/licenses/tzdata/<file>
#   package:<path inside the package>                        already shipped; must exist
#   -                                                        no licence text available (notice only)
# A trailing "/*" (msys2:, ffmpeg:) copies every file of that folder.
#
