# Görsel tasarım referansı

`reference/tasarrım/` kullanıcının GUI tasarımının proje içine alınmış kopyasıdır. Renk, ölçü, yerleşim, font, ekran ve kontrol görünümünü incelemek için tutulur.

Bu HTML/CSS/JavaScript dosyaları RadioS'un uygulama kaynakları değildir. C pencere ve kontrolleri `src/ui/` altında geliştirilecektir. Native program WebView veya tarayıcıya bu klasörü yükleyerek çalıştırılmaz. Tasarımın örnek kayıtları çalışma veritabanına aktarılmaz.

Ana görünüm referansı `reference/tasarrım/index.html` dosyasıdır. Fragmentlerdeki ek görünümler ayrıca işaretlenmiş ikincil referanslardır. İlk kopya kaynakları ve SHA-256 özetleri `docs/source-import-manifest.json` içinde bulunur.
